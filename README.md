# HydroTwin Lab

Lab environment for student collaboration.

This repo is a copy of the `hydrotwin-site` **dev** build @ `f3fe0ee3` (25-year dataset, Oct 2001 - Sep 2026; drift panels; per-station ablation tables), published via GitHub Pages so students can experiment without touching the main project environments (production / dev).

- Live site: https://saurabhkulkarni77.github.io/hydrotwin-lab/
- Station pages live under `stations/` (classic + `-3d` WebXR pages).
- Pushes to `main` redeploy the Pages site automatically.
